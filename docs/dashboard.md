# Native dashboard specification

The dashboard consumes the tenant-scoped query API. MVP navigation: AI Overview (request rate, errors, latency distribution, tokens, cost and reliability coverage); Requests/Trace Explorer (filterable operations, span timeline, retrieval/tool events and linked evaluation); Reliability (verdict counts, unsupported/contradicted claims, score distribution, evaluator version); Models (provider/model usage, latency, errors and cost). RAG and Agent/Tool panels initially show available metadata and explicit no-data states; advanced quality metrics follow evaluator availability.

Every chart states time window, units, data freshness, sample count and active filters. Cost shows currency and pricing provenance; unavailable price is not zero. Reliability coverage distinguishes not evaluated, pending, abstained and failed from PASS. A user can navigate from a trace to claim findings and evidence references without exposing raw content unless capture policy and authorization permit it. Dashboard/API outages show a recoverable error rather than silently empty charts. Test empty, partial, delayed, redacted and cross-tenant states, accessibility of core navigation, and pagination at scale.
